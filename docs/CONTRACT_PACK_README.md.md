# Diké Contract Pack v0.1

This pack formalises the initial shared API and database contract for the Diké implementation.

## Files
- `docs/openapi.yaml` — machine-readable OpenAPI 3.1 contract.
- `docs/API_CONTRACTS.md` — human-readable API rules and endpoint explanations.
- `docs/DATABASE_SCHEMA.md` — relational database schema and migration requirements.
- `docs/INTEGRATION_PLAYBOOK.md` — shared repository, branch, contract-change and integration workflow.

## Important
This is an implementation baseline prepared from the Diké Master Product & Engineering Specification v0.2. It is not proof of a deployed API, database or provider configuration. DX and Jibola should review the contract together before implementation begins. Any agreed changes must be committed to the shared repository and reflected in both the OpenAPI file and the human-readable contract.
